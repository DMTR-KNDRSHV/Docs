### Не реализовано (ожидание)

**Самостоятельные (без CRM)**
- Статистика покрытия — % визитов клиники покрыт CDSS
- Фото/схемы — рентгенограммы, дерматология (отложено, вопрос лицензий)
- Видеоссылки — обучающие видео по процедурам
- AZ-версия — полный перевод всех данных
- Регенерация CSV-файлов

**Ждет CRM/EHR интеграции**
- Персонализация (логин врача, предпочтения)
- Заметки врача к каждому диагнозу
- Избранное (часто используемые диагнозы)
- API для подключения к CRM
- Автозаполнение диагнозов из медкарты
- Push-алерты при сохранении без тестов
- Offline PWA (работа на планшете без интернета)

**Аналитика (ждет CRM)**
- Дашборд compliance — % назначения обязательных тестов по врачам
- Топ-диагнозы с обходами
- Тренды по месяцам
- Средний чек на диагностику по категориям

### Workflow обновления
1. Добавить в CDSS_DB (диагноз)
2. CHAINS_DATA (цепочки)
3. TREATMENT_DATA (лечение + источник)
4. AGE_NOTES (возраст)
5. BREED_DATA (породы)
6. SYMPTOMS_DATA (симптомы)
7. Верификация дозировок по источникам
8. Обновить AZ-версию
