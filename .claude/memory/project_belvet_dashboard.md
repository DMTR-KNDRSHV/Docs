## Проект: Полный аналитический дашборд BELVET

**Клиника:** BELVET — ветеринарная клиника в Баку, Азербайджан. Валюта: AZN.

### Файлы
- **Источник данных:** `Files/all_data_UPDATED_FULL_2026-03-30T13-59-49.xlsx`
- **Дашборд:** `Files/clinic_dashboard.html` (~69 KB, чистый HTML + Chart.js, без Python)

### Структура Excel (8 листов)
- Заголовки в **строке 2** (индекс), данные со **строки 3**
- Загрузка: `header=None`, затем `df.columns = df.iloc[2].tolist()`, `df = df.iloc[3:]`
- Листы: Clients, Pets, Visits, Invoices, Services & Products, Payments, Medical Records, Hospital
- При merge таблиц с общими именами столбцов (Breed) — переименовывать перед merge

### Разделы дашборда (14 разделов с sticky навигацией)
1. **Общая информация** (#general) — KPI (8756 клиентов, 11661 питомцев, 1.32M AZN), виды, породы, оплаты
2. **Финансы** (#finance) — ежемесячная выручка, визиты, рост клиентов, сезонность, LTV по годам
3. **Предиктивная модель** (#predict) — прогноз выручки (полином. регрессия 2 степени), 3 сценария (базовый/оптимист./с рекомендациями)
4. **Операционные** (#operations) — врачи (эффективность, нагрузка), нагрузка по дням/часам, тепловая карта, ТОП-15 услуг
5. **Клиенты** (#clients) — RFM-сегментация (VIP/Лояльные/Новички/Обычные/В зоне риска/Потерянные), ТОП VIP, клиенты в зоне риска, отток, интервалы визитов
6. **ABC/Маржа** (#findetail) — ABC-анализ услуг (43=80%), маржинальность (78%), корзинный анализ, дебиторка (28 223 AZN)
7. **Заболевания** (#diseases) — ТОП-25 диагнозов, динамика, сезонность болезней, по видам
8. **Животные** (#animals) — LTV по видам/породам, риск-профиль пород, смертность
9. **Зоонозные риски** (#zoonotic) — таблица рисков, конкретные кейсы с именами, тренды по кварталам, прогноз
10. **Маркетинг** (#marketing) — источники, география (99.9% Баку), интервалы визитов
11. **Мульти-питомцевые** (#multipet) — LTV по кол-ву питомцев (1=99, 10+=4295 AZN), ТОП владельцев, пакетные предложения
12. **Возраст при первом визите** (#agefirst) — распределение по возрасту, кошки vs собаки, упущенные котята/щенки
13. **Мониторинг здоровья** (#health) — вес/температура, тренды, лихорадка (11.9%), алерты недовес/перевес
14. **Кросс-продажи** (#crosssell) — 88% без вакцинации!, LTV 1кат=38 vs 8кат=800 AZN, охват категорий, допродажи

### Workflow обновления данных
1. Пользователь предоставляет новый Excel файл
2. Извлечь данные через Python (extract script) → переменные
3. Обновить HTML файл с новыми данными (всё встроено как JS-переменные, Chart.js из CDN)
4. Удалить временные файлы (.py, .json)

**Why:** Клиника хочет полную аналитику: финансы, клиенты, заболевания, зоонозные риски, операционка, маркетинг.
**How to apply:** При упоминании clinic_dashboard.html — это ЭТОТ проект. Не нужно объяснять структуру. Сразу приступать к работе.
