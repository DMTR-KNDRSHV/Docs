CDSS - Система поддержки клинических решений

Краткая инструкция для ветеринарных врачей | v1.0

1. Запуск

1 Откройте файл cdss_veterinary.html в любом браузере (Chrome, Edge, Firefox).
2 Файл работает полностью офлайн - интернет не нужен. Можно скопировать на рабочий стол, планшет или флешку.
Совет: Создайте ярлык на рабочем столе для быстрого доступа. На планшете можно добавить в закладки.

2. Интерфейс

Верхняя панель

  • Поиск - основное поле. Ищет по названию диагноза, описанию и симптомам
  • Режим поиска - переключатель: "по названию" / "по симптомам"
  • Фильтры - по категории, уровню алерта, виду (собаки/кошки)
  • Сортировка - по алерту, частоте или алфавиту
  • Тема - переключение темная/светлая тема (кнопка в правом верхнем углу)

3. Основные сценарии использования

Сценарий А: Знаю диагноз - нужен протокол

1 Введите название в поиск (например: "панкреатит")
2 Нажмите на карточку диагноза
3 Откроется детальная информация: описание, обязательные тесты, лечение (со стадированием, если есть), возрастные заметки, породная предрасположенность
4 Отметьте выполненные исследования галочками. При попытке сохранить без обязательных тестов - система покажет предупреждение

Сценарий Б: Не знаю диагноз - есть симптомы

1 Вариант 1 - Поиск: Переключите режим поиска на "по симптомам" и введите симптом (например: "рвота", "хромота", "зуд"). Система покажет все диагнозы с этим симптомом
2 Вариант 2 - Wizard: Нажмите кнопку "Wizard" в нижнем тулбаре. Следуйте шагам: выберите симптомы -> укажите вид/возраст/породу -> ответьте на уточняющие вопросы -> получите ранжированный список дифференциалов
Совет: Wizard особенно полезен при нетипичных случаях - он учитывает комбинацию симптомов, вид, возраст и породу одновременно.

Сценарий В: Мультидиагноз

1 Выберите несколько диагнозов (переключатель "Мультидиагноз" в карточке)
2 Система автоматически проверит конфликты лечения между протоколами (25 правил). Например: НПВС + кортикостероиды, азатиоприн у кошек, перметрин у кошек
Важно: Конфликты с пометкой "КРИТИЧНО" (красный) - абсолютные противопоказания. "ВЫСОКИЙ РИСК" (оранжевый) - требует обоснования. "ВНИМАНИЕ" (синий) - мониторинг.

4. Клинические инструменты

Открываются кнопкой "Клин. инструменты" в нижнем тулбаре. Содержат 9 вкладок:

CRI Калькулятор 16 препаратов. Ввели вес, выбрали препарат и объем раствора - получили сколько мл добавить
SOS Экстренные дозы Одно поле "вес" - все экстренные дозы сразу (адреналин, атропин, диазепам, налоксон и др.)
Шкала боли Glasgow CMPS-SF для собак (24 балла), CMPS-Feline для кошек (14 баллов)
BCS Оценка кондиции 9-балльная шкала WSAVA/AAHA. Идеальный вес, калории, план похудения
Совместимость препаратов Матрица 20x20 IV-совместимости. C = можно, X = нельзя, ? = осторожно
Вакцинальный календарь WSAVA 2024. Core/Non-core для собак и кошек. Пометки для Азербайджана
Антипаразитарный календарь ESCCAP/CAPC. Эндо- и эктопаразиты. Сезонность для региона
Конвертер единиц 11 параметров: ммоль-мг/дл, C-F, кг-lbs, мкмоль-мг и др.
Лабораторные нормы IDEXX. 5 панелей: ОАК, биохимия, электролиты, коагулограмма, моча. Собаки/кошки

5. Стадирование заболеваний

37 диагнозов имеют отдельные протоколы по стадиям. При выборе такого диагноза появляются кнопки стадий - каждая стадия содержит свои критерии, первую линию лечения, поддерживающую терапию, противопоказания и мониторинг.

6. Источники данных

Все протоколы верифицированы по 15+ авторитетным источникам:

  • IRIS, ACVIM, AAHA, AAFP/ISFM, ISCAID, ABCD, RECOVER, WSAVA
  • Plumb's Veterinary Drug Handbook 10th Ed
  • BSAVA Small Animal Formulary 12th Ed
  • MSD / Merck Veterinary Manual
  • PubMed Veterinary Science
  • VetCompass / SAVSNET (эпидемиологические данные)
  • CVP - Compendium of Veterinary Products
Дисклеймер: Протоколы лечения носят справочный характер и не заменяют клиническое решение врача. Дозировки требуют индивидуальной корректировки. Система является помощником, а не заменой клинического мышления.
